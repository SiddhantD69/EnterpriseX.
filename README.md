\# EnterpriseX



EnterpriseX is a production-grade Enterprise Resource Planning (ERP) platform.



\## Vision



One system → One data model → Connected business processes → Real-time information.



\## Technology



\- Desktop: Tauri + React + TypeScript

\- Backend: Node.js + TypeScript

\- Database: PostgreSQL

\- Infrastructure: Docker

\- Version Control: Git



\## Project Status



Foundation V1 — Development



\## Architecture



EnterpriseX uses a modular architecture with clear ownership boundaries between business domains.



Major domains include:



\- Core Platform

\- Security \& Identity

\- Data Platform

\- Finance

\- Supply Chain

\- Sales

\- Warehouse

\- Manufacturing

\- HR

\- CRM

\- Integration

\- Analytics

\- QA

\- DevOps / Release
